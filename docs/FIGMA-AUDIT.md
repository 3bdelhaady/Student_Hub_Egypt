## Security and state preservation

- Account mode is stored in `account_preferences` through migration 0010. It is a view preference, not authorization.
- Agent mode requires an active assignment with read permission and active institution/faculty/group at save time. Dashboard reads and mutations retain their existing independent scope checks.
- Students cannot enable agent mode by editing the browser radio input.
- No existing password or activation status is changed by this milestone. Live demo setup and any existing-account rotation remain separate owner-controlled work.
- National ID collection was added after the owner explicitly requested it. It validates format/date, not government identity. Its fingerprint is excluded from auth responses and public profiles. No fake email or OTP flow was added.
