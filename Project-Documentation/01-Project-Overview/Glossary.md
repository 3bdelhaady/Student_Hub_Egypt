# Glossary

| Term                     | Meaning in this project                                                                                     |
| ------------------------ | ----------------------------------------------------------------------------------------------------------- |
| Student Hub Egypt        | Startup operating the platform.                                                                             |
| Student Center           | English rendering of مركز الطلاب used for the card/balance and platform services.                           |
| Student Center balance   | Intended electronic balance used for in-platform payment; currently zero and not top-up enabled.            |
| External payment gateway | External way to fund that balance; no specific provider selected.                                           |
| Institution              | University-linked or private-sector entity with its own active state.                                       |
| Faculty                  | University-owned unit selected from a controlled list.                                                      |
| Student affairs          | Scoped institutional staff function reviewing students and assigning permitted Coordinator capabilities.    |
| Coordinator              | Capability of an existing student account, associated with a union or activity, not a separate signup role. |
| Student union            | Default faculty organization; preserve existing identifiers and assignments.                                |
| Student activity         | Named activity added by authorized affairs staff.                                                           |
| Platform administrator   | Separate server-side platform grant, not a user-selected signup type.                                       |
| Membership               | A user's one university affiliation with role and status.                                                   |
| Agent                    | Institution-linked assignment with department, scope and section rights.                                    |
| Activation               | Membership/agent approval, not proof of email ownership.                                                    |
| Verification             | Email ownership confirmation; does not approve membership.                                                  |
| Portal entry             | Domain item such as ticket, team, volunteer opportunity, service or commerce listing.                       |
| Gumball                  | Mascot name and name of the planned AI virtual assistant.                                                   |
| Fitness Club             | Separate application intended to use the Hub account bridge and future Student Center balance.              |
| Demo                     | Development operating boundary, not an entitlement to use real personal data or funds.                      |
